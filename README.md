# RoiBotWorking

בוט Windows שמזהה משולשי BUY/SELL בגרף TradingView ופועל דרך ממשק המשתמש, ללא API של ברוקר. המאגר כולל את קוד Python, קובצי Pine והבדיקות המקומיות.

## הגרסה הפעילה

- מקור האיתותים: `instant_breakout_rsi_vwap_1sec_3bars.pine`, על גרף נרות רגילים של שנייה אחת.
- האינדיקטור ממתין לשלושה נרות שהושלמו אחרי נר המקור. הוא מציג את המשולש בתחילת הנר הבא; Python אינו מוסיף המתנה נוספת.
- הבוט סורק את גרף השנייה המוגדר ומאפשר מועמד כניסה רק ממשולש חדש באזור הנרות הימני. משולשים קיימים מקבלים baseline בהפעלה.
- כמות הכניסה חייבת להיות 1. פוזיציה פתוחה, פקודות ממתינות או מידע לא מאומת חוסמים את שני הכיוונים.
- נתוני החשבון נקראים באמצעות Windows UI Automation. זיהוי קצר של פוזיציה/פקודה נשמר עד שהבוט מטפל בו.
- אימות הכפתורים משלב מיקום מהממשק, בעלות חלון ופיקסלים של כרטיסי BUY כחול / SELL אדום.

`--strategy` הוא תווית ליומן. הוא אינו מתקין או מחליף את האינדיקטור שעל הגרף.

## התקנה מקומית

```powershell
py -m pip install -r requirements.txt
Copy-Item nq_bot_config.example.json nq_bot_config.json
```

ערוך את `nq_bot_config.json`: חשבונות מורשים, כתובת פריסת TradingView, כותרת החלון, מספר הגרף ותיאורי הסימבול/טיים־פריים. הפרטים בדוגמה הם placeholders ואינם מאפשרים מסחר ללא התאמה.

הוסף את קובץ Pine המתאים מ־`אינדיקטוריםTRADING VIEW` לגרף השנייה. אל תציג באזור זה מקור משולשים נוסף באותם צבעים. בחר ב־TradingView כמות 1 ואת פריסט היציאה הרצוי, והשאר את לשונית Positions פתוחה ואת הגרף והכפתורים גלויים.

כייל את כפתורי המסחר באמצעות ריחוף ו־F8, בלי ללחוץ עליהם:

```powershell
py nq_triangle_bot.py calibrate-buttons
```

הסריקה האוטומטית מופעלת בדוגמה באמצעות `scan_bound_chart=true`; היא אינה דורשת כיול מלבן מחדש כשהמחיר עולה או יורד. `calibrate-region` בוחר שוב סריקה ידנית. אפשר להתאים את צבעי המשולשים באמצעות `calibrate-colors`.

## בדיקה ללא עסקאות

```powershell
py nq_triangle_bot.py check-position
py nq_triangle_bot.py test --strategy 1sec-after-3bars --test-seconds 30
```

TEST אינו לוחץ על כפתורי מסחר. בדוק גם שהמשולשים החדשים מתקבלים באזור הנרות החיים, ולא רק ששורת המצב מציגה READY.

## הפעלה

```powershell
py nq_triangle_bot.py run --strategy 1sec-after-3bars
```

RUN שולח לחיצות מסחר בחשבון המחובר. הוא דורש One-click ואת הפריסט הרצוי ב־TradingView; הבוט אינו מאמת את פרטי ה־TP/SL או את מחיר המילוי. ESC או Ctrl+C עוצרים את הבוט, בלי לסגור פוזיציה אצל הברוקר.

אם נותרה נעילה, אפשר לבחור איפוס מאומת כחלק מההפעלה:

```powershell
py nq_triangle_bot.py run --strategy 1sec-after-3bars --reset-position-lock
```

האיפוס דורש שלוש קריאות מלאות ועצמאיות באותו חשבון: ללא פוזיציה, ללא פקודות וכמות 1. אם התנאים אינם מאומתים, ההפעלה מסורבת. אין מחיקה עיוורת של הנעילה, סגירת פוזיציות או ביטול פקודות. אחרי האיפוס עדיין נדרשים אימות הכניסה ואיתות חדש.

לבדיקת אפשרות האיפוס בלבד:

```powershell
py nq_triangle_bot.py test --strategy 1sec-after-3bars --reset-position-lock --test-seconds 10
```

ב־TEST האיפוס מדומה בזיכרון וקובץ הנעילה נשאר ללא שינוי. סגירה מאומתת משחררת את החסימה אוטומטית; ניסיון כניסה שלא נצפתה אחריו שום ראיית פעילות/סגירה עדיין יכול להישאר נעול. קריאת מסך אינה נעילה אטומית אצל הברוקר.

## בדיקות הקוד

```powershell
py -m unittest discover -s tests -b -q
```

מצב הבדיקות בהעלאה הראשונית: **233 מתוך 234 עברו**. הכשל הקיים ב־`test_regime_policy.test_builds_separate_reproducible_variants_and_relative_exits` הוא הבדל בכותרות של שתי אסטרטגיות 5sec מול תבנית הייצור. הבדיקות אינן אימות רווחיות, קומפילציה של Pine או עסקת אימות אצל הברוקר.

## קבצים ותיעוד

- `position_guard.py` — חשבון, פוזיציות, פקודות ונעילת כניסה.
- `entry_surface.py` — אימות חזותי של כפתורי המסחר.
- `signal_tracker.py` — זיהוי ומעקב משולשים.
- `bot_journal.py` — יומן ריצה מקומי.

- `POSITION_GUARD_SETUP.txt` — פרטי מנגנון החסימה והאימות.
- `MAMBA_VIDEO_SETUP.txt` ו־`REGIME_5sec_SETUP.txt` — האינדיקטורים הנוספים והגרסאות הניסיוניות.
